# SentryDigest address compatibility

This branch keeps the former GitHub Pages address working. GitHub Pages serves it
with the custom domain `sentrydigest.ricomanifesto.com`, so requests to the old
`ricomanifesto.github.io/SentryDigest/` address redirect to the same path on
https://sentrydigest.ricomanifesto.com/. The site itself is built and deployed from `main`; nothing here
is published there.
